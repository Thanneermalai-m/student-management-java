# Student Management System

## Overview

A console-based Student Management System developed using Java. The application allows users to manage student records using CRUD operations and file storage.

## Features

* Add Student
* View Students
* Search Student
* Update Student
* Delete Student
* Sort Students by Marks
* Save Records to File
* Load Records from File
* Duplicate Roll Number Validation

## Technologies Used

* Core Java
* OOP Concepts
* Collections Framework
* Exception Handling
* File Handling

## Project Structure

* Student.java
* StudentManager.java
* FileHandler.java
* Main.java

## Learning Outcomes

* Object-Oriented Programming
* Collections Framework
* File I/O
* Exception Handling
* Console Application Development
